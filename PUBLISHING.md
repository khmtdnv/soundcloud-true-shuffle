# Инструкция по публикации в Chrome Web Store

## Шаги для публикации в Chrome Web Store:

1. **Перейдите в консоль разработчика Google Chrome**:
   Откройте [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole/).

2. **Авторизация и регистрация аккаунта разработчика**:
   - Войдите под своим аккаунтом Google.
   - Если вы еще не регистрировались как разработчик Chrome Web Store, потребуется принять соглашение и оплатить единоразовый взнос $5 (взнос Google за регистрацию аккаунта разработчика).

3. **Загрузка расширения**:
   - Нажмите кнопку **«Создать элемент» (Add new item)** в правом верхнем углу.
   - Загрузите созданный файл `sc-scroller.zip`.

4. **Заполнение карточки расширения**:
   - **Название**: SoundCloud Full Shuffle Fixer
   - **Краткое описание**: Автоматически подгружает все треки в очереди SoundCloud перед перемешиванием.
   - **Категория**: Music / Accessibility / Productivity.
   - **Иконка**: Выберите `icons/icon128.png`.
   - **Скриншоты**: Загрузите 1-2 скриншота работы SoundCloud с плеером.

5. **Отправка на проверку**:
   - Нажмите **«Отправить на проверку» (Submit for review)**.
   - Автоматическая и ручная модерация Google обычно занимает **от 2 до 24 часов**. После проверки расширение станет доступно всем пользователям в поиске Chrome Web Store и по прямой ссылке!
